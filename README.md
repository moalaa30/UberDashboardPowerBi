# Uber Ride Analytics Dashboard

## 📊 Project Overview

An interactive Power BI dashboard designed to analyze Uber ride data
and provide insights into bookings, revenue, trip distance, and ride trends.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📌 Dashboard Features

- KPI analysis
- Interactive filters and slicers
- Revenue analysis
- Ride demand analysis
- Trip distance analysis
- Vehicle type analysis
- Payment method analysis
